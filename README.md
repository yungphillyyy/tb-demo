# Tuberculosis Detection from Chest X-Ray Images

A web-based application built with **Python**, **Streamlit**, and **MobileNetV2** to demonstrate deep learning-based analysis of chest X-ray images for preliminary tuberculosis (TB) screening.

## Overview

This project provides a simple web interface where users can upload chest X-ray images and submit them for analysis by a deep learning model.

The application was developed for educational and research purposes to explore the use of deep learning in medical image analysis.

## Features

- Upload chest X-ray images in JPG, JPEG, or PNG format.
- Interactive web interface built with Streamlit.
- Deep learning model based on MobileNetV2.
- Preliminary screening support through model predictions.

## Tech Stack

- **Programming Language:** Python
- **Web Framework:** Streamlit
- **Deep Learning:** TensorFlow/Keras (confirm against the project dependencies)
- **Model Architecture:** MobileNetV2

## Getting Started

### Prerequisites

- Python installed on your computer.
- Git installed on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yungphillyyy/tb-demo.git
   ```

2. Navigate to the project directory:

   ```bash
   cd tb-demo
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the Streamlit application:

   ```bash
   streamlit run app.py
   ```

   Make sure the main application filename and dependency file match the files in this repository.

## Limitations and Disclaimer

This application is intended for educational and research purposes only. Its predictions must not be used as a substitute for professional medical evaluation, diagnosis, or treatment.
